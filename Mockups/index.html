❄ Technician Time Management Module

A new module that plugs into the existing YES ERP. It captures technician time bookings against each Job, classifies time as Normal / Overtime, values it using Industry & Location-based labour rates, and feeds efficiency, productivity and performance reporting. All transactions are linked to the existing Job Code, so labour finally joins Material, GRN, Expense and Invoice in the job picture.

Front-End

ASP.NET 4.8 Web Forms (.aspx)
Same UI theme as current YES ERP

Back-End

Oracle Database
New TM_* tables + views, PL/SQL packages

Integration

Reuses existing Employee, Customer, Supplier & Job Order masters via Job Code

Interim Data

Monthly dump / mapping files for Customer→Industry & Labour Rates (import screens)
How it links to the existing ERP — the Job Code is the common key

Every cost document already carries the Job Code. We simply add one more transaction type — Time Booking — that also stamps the Job Code, so it rolls up with everything else:
GRN + Material Issue + Expense + Technician Time (NEW) = Job Cost  →  vs Invoice (Revenue) = Job Profitability

Screens in this proposal

Click any screen to open the mock-up. Master  Transaction  Report / Dashboard

1. Work / Labour Type Master Phase 1

Chargeable, Warranty, Non-Chargeable (Training, Redo, Housekeeping, Idle). Drives COGS / expense behaviour.

2. Industry Master Phase 1

OG, GC … used to select the labour rate. No cost-center mapping needed.

3. Customer → Industry Mapping Phase 1

Maps Customer No to Industry Code. Interim dump-file import.

4. Labour Rate Master Phase 1

Rate by Location × Industry × Time Type (same for all technicians). Effective dates, monthly import.

5. Duty Timing & Calendar Phase 1

Duty hours & weekends → auto Normal/Overtime. Allowed hours, 192-hr benchmark.

6. Task Master Phase 1

Library of tasks (Disassemble, Assemble, Testing) that form the scope of work on a WO. Booked per task.

7. Task Standard Hours Phase 1

"Cheat-sheet" standard hours per task, keyed by Manufacturer · Model · Series · Component · Task.

8. Time Booking Posting Phase 1

The core transaction. Technician time booked per Task (Job No + Task) — start/end, net hrs, time type, rate, cost.

9. Efficiency & Productivity Report Phase 1

Actual vs task standard & 192-hr target, overtime, chargeable %, loss time.

10. Performance Dashboard & KPI Phase 1

Executive KPIs — utilisation, efficiency, segment margin, overtime trend.
