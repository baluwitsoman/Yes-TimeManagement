❄ Task Master

The library of standard tasks that make up the scope of work on a Work Order (e.g. Disassemble, Assemble, Testing). One Work Order has one-to-many tasks; time is booked per task and keyed as Job No + Task. Standard hours for each task are maintained in the Task Standard Hours master.
